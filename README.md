Yang saya Analisa tentang root:x:0 adalah sebagai berikut :
1.	Root adalah nama group utama sebagai administrator atau disebut juga dengan root
2.	X adalah password group yang digunakan untuk menyimpan file denga naman dikarenakan sudah di enskripsi
3.	0 adalah id group
